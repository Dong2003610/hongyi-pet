# 桌宠与每日任务清单：当前产品说明

桌宠负责随手记事、聊天操作和陪伴；[每日任务清单](https://dong2003610.github.io/daily-task-list/)负责完整管理。两端使用原来的账号和任务数据库，无需新增账号或迁移数据库表。以下是 2026-10-29 版本的行为。

2026-10-30 的关闭按钮、草稿和设置保存等交互修复见 [本轮自检记录](20261030-self-check.md)。

## 1. 统一任务、提醒和专注规则

- 任务日期、序号、提醒时间均按北京时间。列表沿用网页的完成状态、手动排序和优先级规则。
- 登录后的一次性提醒，优先更新同名已有任务；没有匹配项才新增带提醒的任务。模糊或同名匹配先选择，不直接猜测。
- 每天、工作日的个人提醒仍保存在本机，不为每次喝水等提醒创建任务。未登录时也能使用本机提醒。
- 设置“桌宠接收任务提醒”后，账号元数据记录提醒接收端；新版网页会暂停该端的通知，并提供“改由网页提醒”入口。桌宠退出期间无法提醒，选择桌宠接收时需要保持它运行。
- 自由专注和任务专注共用一套计时、暂停、继续和结束逻辑；自由专注无需登录。任务累计时长写入原 `elapsed_seconds`，绝对值保存只增不减，重试不会重复累加。
- 两端的任务专注通过账号元数据进行占用检查和每 15 秒续期，暂停、结束、退出时尝试释放，异常断开后 90 秒过期。此方案是尽力协调；没有数据库原子锁，几乎同时启动仍有竞争窗口，下一次续期会检测冲突并暂停。不要把它当作严格的多端计时合并。
- 遗留接续沿用网页的确定性 ID、取消标记和目标日期去重，已存在的副本不会重复创建。接续预览确认后保存，原任务保持不变。

## 2. 以聊天完成任务操作

双击人物打开快捷聊天，Enter 发送，Esc 隐藏，“打开小屋”恢复完整面板。两个窗口复用同一会话与操作链路。

可直接尝试：

1. “今天有哪些任务” → 展示实际任务卡片，可点击选择、完成或专注。
2. “帮我把第二项任务改成高优先级可以吗？” → 按刚才展示的顺序操作。
3. “选中这项”后说“改到明天”“优先级改为高”“做完了” → 沿用当前任务上下文，聊天顶部显示选中名称。
4. “十分钟后提醒我写报告” → 为已有报告任务设置提醒，避免重复创建。
5. “先做这个，25分钟” → 对当前任务开始专注；“暂停一下”“继续专注”“结束计时”控制同一轮计时。
6. “自由专注25分钟” → 无需选任务，保存本机进度。
7. “今天先做什么” → 推荐下一项待办，可先做 5 分钟。
8. “拆解周目标：完成产品上线”或“今天没做完的明天再做” → 先生成预览，确认后再写入。

新增时也支持“新增高优先级任务：提交报告”“新增提交报告高优先级任务”“麻烦你帮我新增一个明天的高优先级任务：提交报告”，中、低优先级同样适用。优先级描述不会混进任务名；只说“新增一个高优先级任务”时会要求补充名称。需要把“高优先级”等字样保留为标题正文时，用引号包住标题，例如“新增任务：『高优先级任务说明』，优先级低”。

中文/数字序号对应当前展示列表；模糊名称或多个候选通过卡片选择。任务上下文 30 分钟过期，待确认候选和批量预览 5 分钟过期，切换账号后旧动作失效。本地明确规则可离线解析；较自由的表达使用已配置的 AI 解析当前指令，再由主进程验证，任务列表和凭证不发送给模型。普通聊天仍沿用原 AI 服务。

## 3. 可核对的执行反馈

成功卡片只在收到保存响应后展示；修改后提供撤销，撤销使用版本检查，避免覆盖网页的新修改。网络丢失响应时显示结果尚未确认，并优先读取当前状态。新增重试复用原 ID。

任务操作和卡片保留在本机聊天记录中，与普通 AI 上下文分开；历史卡片不可执行，需重新查询后操作。任务记录按账号隔离，退出或换账号会清除当前选择。记住登录使用 Electron safeStorage 加密会话，不保存密码。

## 4. 小屋只保留“对话＋今天”

- 对话：聊天、任务卡片、当前任务和专注小条。
- 今天：共用专注卡片、今日或全部未完成任务，手动添加与后续提醒默认折叠。
- 顶部账号入口：登录原用户名和密码、退出账号。
- 顶部爱心：互动和陪伴数值。齿轮：AI、提醒、简报、免打扰等设置。
- “完整清单”打开网页，处理完整的周计划、重复规则、批量整理等管理工作。桌宠不再维护单独的周计划编辑面板。

## 5. 让陪伴服务于做事

专注开始时停止自主走动，专注和免打扰期间减少主动说话、打字反应和久坐打扰。完成任务会有庆祝反馈，免打扰时保持安静。

早晚简报读取真实任务和累计时长，不编造总结；默认关闭，可在设置或聊天中开启。默认早报 09:00、晚报 21:00、免打扰 22:00～08:00，均为北京时间。免打扰结束后补查到期任务提醒。休眠暂停专注，重启恢复为暂停态；同步失败保留进度供重试。
