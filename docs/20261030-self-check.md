# 2026-10-30 交互自检

## 已修复

1. **小聊天窗关闭按钮点不动**：标题容器覆盖了关闭按钮的点击区域。为关闭按钮设置独立层级，扩大到 32px，增加可读名称，并给快捷窗标题预留按钮空间。真实 Electron 测试确认点击后窗口隐藏，再次双击人物可重新打开。
2. **提醒设置被刷新覆盖**：原先只在输入框有焦点时保护表单，失去焦点后的每秒轮询会恢复旧值。现在跟踪未保存修改，保存失败保留输入并在当前设置区域显示原因；保存中防止重复提交，切换账号后丢弃上一账号草稿和过期响应。
3. **发送失败丢失输入**：回复传输失败时恢复原文；用户已输入下一条草稿时保留新草稿。任务操作丢失响应可能已经保存，提示先查询状态，避免盲目重复新增。
4. **等待回复时操作冲突**：发送或卡片执行期间禁用清空和快捷提问，仍允许输入下一条草稿。清空失败保留原有对话。
5. **历史记录覆盖新消息**：历史读取增加版本检查，较晚返回的旧历史不会抹掉刚发送的消息，读取失败也不阻止继续聊天。
6. **专注按钮键盘焦点丢失**：专注小条使用固定按钮，轮询只更新文字和状态，不再每秒重建按钮。
7. **AI 状态文字过早声称连接成功**：保存配置后显示“AI 已配置”，实际点击连接测试成功后才报告服务可用。
