# 2026-10-30 人物比例与动作整理

## 修改

- 原画保留在 `incoming-assets/motion-originals-20261030/`，包括 52 张动作帧、身份母图和修改前的 app 配置。正常运行导入 49 张动作帧，归档素材不进入桌宠窗口资源。
- 保留 512×512 透明画布。以待机人物为比例参考，按已检查的人脸尺度缩小异常放大的动作，脚底/接触面统一在第 485 行，水平中心约为第 256 列。跳跃、弯腿和躺姿没有按完整轮廓高度强行拉成站姿。
- 行走帧没有头顶道具，统一其站立轮廓高度为约 330px，替换前左右两组分别为 363–425px、347–402px。各组移出最后的站定帧，保留 5 张移动姿势，步进由 130ms 调为 140ms。
- 吃东西移出突然踢腿的 `eat-04.png`，保留 4 张取食/咀嚼姿势，步进调为 160ms。摸头调为 160ms，探头调为 150ms。
- 按用户后续反馈恢复六张睡觉原图，像素、尺寸、顺序均与归档原图一致，不做比例或对齐处理。只把姿势切换间隔从 1500ms 调为 2500ms；睡觉交互延长为 15 秒，确保六种姿势都能完整展示，再恢复待机。
- 呼吸用于待机和睡觉，睡觉恢复原有的 3.2 秒呼吸参数；行走、进食不再叠加呼吸拉伸。开心动作保留起跳位移，最后一帧已在素材中统一比例，删除运行时额外 0.73 倍缩小，避免重复缩放。

## 可复现处理和预览

在 `app/` 运行：

```powershell
npm run process:motion
npm run qa:motion
```

`tools/motion-registration.json` 保存参考尺度、逐帧标注和原图 SHA256。处理器只读取归档原图，原图变动时要求重新检查标注；重复处理产生相同字节，不会连续缩小。处理时检查透明边距，拒绝裁掉可见人物。

`app/qa/20261030-motion/preview.html` 是独立的修改前/后动画对照页，可直接用浏览器打开，切换十种动作、六档窗口大小、速度，暂停或单步检查。该页面嵌入全部图片，不需要联网、登录或启动桌宠。同目录提供 `before.png`、`after.png` 和行走/跳跃/进食/睡觉 GIF；预览由 `tools/preview-motion.mjs` 重新生成。

## 验证及边界

- 128 项单元测试通过，包含全部运行帧的尺寸与透明边界、非睡眠帧的基线和水平中心、左右行走高度差，以及原图归档校验。睡眠测试检查六张图逐字节保持原样，每帧停留 2.5 秒，15 秒后回到待机。
- TypeScript 检查通过。真实 Electron 人物交互回归覆盖跳跃落地、重复点击、拖动方向与停止恢复、六档尺寸、气泡及过期 AI 回复；睡眠用例检查六张姿势完整播放和原有 3.2 秒呼吸，五帧行走与进食不叠加呼吸。
- 预览 HTML 在独立隐藏 Electron 窗口通过图片解码、五组动作和六档尺寸检查，没有 JavaScript 错误。已检查其左右行走、跳跃、睡眠和进食截图。
- 未请求生图 API，未重画人物，未修改任务服务、真实账号或运行中的用户桌宠。源画的侧脸、头身比例和四肢造型仍不完全一致，本轮处理减少了尺寸与落点跳变，但不能把独立姿势图变成完全连续的动画；后续需要基于同一角色补画动作中间帧。
- 旧通用素材质检以轮廓包围盒面积判断动作间缩放。原资源处理方式使不同姿势接近相同轮廓面积；本轮改用人物比例后，这一规则会把展开四肢和蹲姿的正常面积差报为 `SCALE_DRIFT`。新报告为 11/45，通过比例不能作为本轮质量结论；`happy-02` 的弯腿连通区域还被报为地面残留，已核对对照图，未删除裤腿或放宽规则。报告保留在 `app/qa/20261030-motion/source-qa/`，未标记为全部通过。
- 原有配置还存在 `typingReaction/filePocket` 与触发声明不一致，以及面板静态素材导入检查不匹配。本轮保留这些已有问题，没有修改功能开关或绕过检查。
- 配置校验现在允许 2–8 张真实交互姿势、4–8 张行走姿势，或者显式声明且启用的单帧呼吸循环；不再为凑固定帧数保留不适合的姿势。修改有独立 builder 迁移记录，构建与开发启动的保护保持开启。

本轮交付为源码、处理工具和动画预览。已存在的便携版需要重新打包后才会使用新素材。
